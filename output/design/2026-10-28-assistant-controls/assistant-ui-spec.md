# 官网客服屏幕设计交付说明

2026-10-29。本轮提供 29 个可点击的设计状态和一份屏幕 PDF。没有改官网产品源码，也没有接真实模型、询盘保存、企微或邮件服务。原型里的按钮只切换示例画面。

## 从哪里看

- `assistant-ui.html`：浏览器里按左侧目录选择状态，可切换桌面/手机视图，也可按“询盘”“停止”“恢复”“历史”旅程逐步看。
- `assistant-ui-screens.pdf`：29 页，一页一个状态，含完整展开后的面板和处理规则；便于手机阅读与讨论。
- `screens.json`：每个状态的进入条件、允许动作、退出状态、实现状态与验收注意项。
- `ui-validation.json`：本轮实际浏览器检查结果。原型通过不代表产品后端已经具备这些能力。

## 沿用真实网站的部分

实际核对 `origin/main` 的 `apps/site/src/islands/ai/AssistantWidget.tsx`，基准 SHA `b3d63ac14f0bd1fac700e9b7c403e61076cf1ba4`；也查看上一轮的线上面板截图。沿用右下角 24rem 面板、`bg-brand-950` 深蓝头部、品牌蓝用户气泡、黄色入口强调、浅色 transcript、圆角和固定输入区。没有重做官网视觉。

工具结果卡片、比较、询盘确认、历史恢复等是目标设计。标为“现有部分”的状态只表示可复用已有外观或代码，不代表整个状态已在线上正常运行。

## 停止与任务控制的区别

官网 `Stop` 只停止当前买家的一次回答。点击后先显示“Stopping this answer”，服务端确认后才显示“已停止”。停止结果不明时给查询路径，保留问题与已有文字；重新回答创建新的一次回答。收起面板只改变界面，不能撤销已经提交的询盘。

Hermes 的销售任务暂停、取消、接管、恢复属于另一套企微交互。不能把官网 Stop 或群里的会话中断当成销售业务任务已暂停。对应企微设计在同目录 `wecom-controls.html`，官网原型不会调用它。

## 正式询盘的边界

一般产品咨询继续对话，模糊采购可以先整理需求，未选定型号仍可准备询盘。只有客户核对需求与联系方式、明确勾选本次联系同意并点击确认提交，才进入保存画面。保存成功后的回执、自动销售准备、邮件发送是三个不同事实。原型不会真的保存，成功画面是样例。

字段错误应保留已填内容并聚焦首个错误。保存超时先核对原提交，不创建第二条询盘；停止当前回答、关面板或网络断开均不能被解释为撤销已发出的保存请求。

## 本轮实际验证

独立 Chrome 浏览器检查了 29 状态 × 320、390、768、1024、1440 五种宽度，共 145 项布局检查。检查页面和面板横向边界；纵向长内容允许正常滚动。键盘与交互旅程另行检查：停止确认后重答、验证失败保留字段、明确同意后提交、保存与发送事实区分、Escape 收起并返回入口焦点、Shift+Enter 换行、普通提问不产生外部请求。

可复查时先在独立终端以本目录为根启动 `python3 -m http.server 62040 --bind 127.0.0.1`，再执行 `node /tmp/assistant-ui-validate-20261029.cjs`；它使用本轮独立临时静态服务和现有 Playwright 依赖，不访问真实账号。检查结束后本轮创建的临时服务和独立浏览器均已关闭。PDF 截图由同一原型展开内容后生成，源码未因截图改成生产 UI。脚本是当前机器的临时检查工具，不能据此声明已有仓库 E2E 测试或 CI。

## 本轮具体修正与依据

应用 `humanizer` 和 UI/UX Pro Max 时实际读了本目录 `assistant-ui.html`、`build_ui.py`、`screen-data.js`、`screens.json`，以及官网 main 的 AssistantWidget 和既有线上截图。技能搜索使用 `loading error recovery chat accessibility`（UX）及 `focus keyboard dialog responsive`（React），核对了清楚恢复路径、可被辅助技术播报的错误和焦点管理。

将“点击停止就显示已停止”的笼统表述拆成“请求已发出 / 停止已确认 / 结果不明”；这会影响人是否错误重开任务。原型代码同时修正按钮触达面积到 44px、联系同意不预勾选、校验失败保留字段、错误焦点。没有把这些原型修正说成线上问题已修复。

仍需真实实现与验收：受理/停止/重试/历史接口、准确运行身份、产品工具与实时公开字段、受控询盘保存、流事件去重、断线恢复、实际移动端输入法及屏幕阅读器。原型的 145 项几何检查和几条旅程不覆盖这些服务器行为。
