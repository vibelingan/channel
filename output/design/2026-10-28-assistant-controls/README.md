## 企微端推荐的实际操作

一个主要工作入口，正常运行默认静默；待审阅、缺资料与异常才通知。人点击卡片或引用带短号的通知定位任务，短操作留在群里，每次都有简短回执；长讨论按需私聊同一机器人，明确显示是哪条任务。第一期不默认新增日志群或每任务一个群。

例如：引用“Q-1042 · ACME · 跟进稿v3”说“暂停这条”，先收到“Q-1042暂停已受理”，后台保存停止点后收到“已暂停”。其他任务继续。销售另行选择“继续准备”才恢复，旧批准不会恢复。没有选定对象时列候选，不猜“最新任务”。

当前Hermes的忙时会话中断不等于这个流程。现有Sales还没有面向销售人员的暂停、接管、恢复、审批入口。官方智能机器人SDK支持卡片及按钮，但当前适配器尚未把它们接为Sales控制。单独增加单向告警Webhook也不会自动解决这部分。

“迭代”就是根据意见或检查改下一版。例如邮件v3经销售意见改成v4；v3保留，v4需重新审核。它不是另一个系统名。
