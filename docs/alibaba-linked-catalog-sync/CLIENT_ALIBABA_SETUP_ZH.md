# 阿里巴巴账号设置说明（客户操作步骤）

请把这份说明发给阿里巴巴国际站卖家账号的负责人。即使不了解我们的系统，也可以按照下面的步骤完成操作。

## 需要您做什么，为什么要这样做

我们会把您的 Alibaba.com 供应商账号连接到您的网上商店。连接后，商店里的商品价格和库存可以跟随供应商的实际信息更新，不需要一直手动填写，也能减少信息过期的问题。

您只需要完成两件事：

1. 在阿里巴巴应用中添加一项设置，只需操作一次，大约需要两分钟。
2. 在您商店的管理后台点击一次，批准连接。

我们不会要求您提供阿里巴巴密码，也不会收到您的密码。批准操作会在阿里巴巴官方网站上完成。批准后，阿里巴巴会向我们的服务器提供一把可以随时撤销的访问密钥。您可以随时在阿里巴巴控制台中取消授权。

---

## 第一部分：添加回调地址（请先完成这一步）

“回调地址”就是您批准连接后，阿里巴巴把浏览器送回的地址。阿里巴巴只允许跳转到应用中已经登记的地址，所以必须先添加这个地址，之后才能正常批准连接。

**请准确添加以下地址：**

```
https://supplychainsai.com/api/alibaba-catalog-sync/oauth/callback
```

请直接复制粘贴，不要手动输入。地址必须完全一致：末尾不能有斜杠，不能有 `www.`，并且必须以 `https` 开头。

**操作步骤：**

1. 打开 **open.alibaba.com**，使用拥有该应用的账号登录。
2. 进入控制台并找到您的应用，通常位于 **控制台 → 我的应用**（Console → My Apps）。
3. 打开 **App Key 为 `511630`** 的应用。
4. 找到回调地址设置。不同版本的控制台显示可能不同，请在以下位置查找：
   - **授权管理**（Authorization Management）
   - **应用信息 → 回调地址**（App Information → Callback Address）
   - **OAuth 配置**（OAuth Configuration）
   - **基本信息**或**应用详情**页面中，名称为 *Redirect URI* 或 *回调 URL* 的输入框
5. 把上面的地址粘贴到输入框中。
   - 如果里面已经有其他回调地址，请**新增**这个地址，不要替换原来的地址。
   - 如果控制台允许保存多个地址，也请添加下面这个备用地址。它会通过另一条路径到达同一个位置：
     ```
     https://diversity-123-d9grnqfux221323bb.service.tcloudbase.com/api/alibaba-catalog-sync/oauth/callback
     ```
6. 保存设置。

设置有时需要几分钟才会生效。如果刚保存就无法完成第二部分，请先等待五分钟，然后再试一次。

## 第二部分：批准连接

请先保存第一部分的设置，并等待我们确认商店更新已经上线。我们会通知您什么时候可以继续。

1. 登录商店的管理后台。
2. 在左侧菜单中打开 **Alibaba Sync**。
3. 点击 **Connect**。
4. 页面会跳转到阿里巴巴。如果系统要求登录，请先登录，然后批准连接请求。
5. 阿里巴巴会把您送回管理后台。页面会显示账号连接成功，或者显示具体的失败原因。

如果连接失败，请把页面上的提示截图发给我们。提示会说明失败发生在哪一步，比只告诉我们“连接失败”更容易排查问题。

---

## 第三部分：进行第一次同步

1. 在同一个页面点击 **Run now**。
2. 运行记录表中会出现一行新记录，显示本次同步读取了多少个商品、多少个商品有问题；如果同步提前停止，也会显示简短原因。

**这时公开商店里的内容还不会改变。** 系统会先读取供应商商品，并把它们放在后台等待检查。只有管理员主动把商店商品与供应商商品连接起来后，该商品才会使用供应商价格。系统不会自动发布任何商品。

现阶段，只有管理员点击 **Run now** 时才会开始同步。等最初几次手动同步都正常完成后，我们才会另行开启定时自动更新。

## 常见问题

**连接后，你们可以进入我的阿里巴巴账号吗？**  
不可以。我们只能通过阿里巴巴官方接口读取您的商品信息。您可以随时在阿里巴巴控制台中取消授权。

**商店里的价格会马上改变吗？**  
不会。商品信息会先进入后台等待检查。只有管理员主动连接商店商品和供应商商品后，该商品才会显示供应商价格。

**我需要把密码保存在哪里吗？**  
不需要。整个过程不使用您的密码。您批准连接后，阿里巴巴会直接向服务器发放访问密钥，服务器会加密保存这把密钥。

**如果发现问题，我应该联系谁？**  
请把管理后台页面截图发给我们，截图中要包括运行记录和页面显示的提示。系统会记录每次同步的结果，通常通过这些信息就能找到问题原因。
