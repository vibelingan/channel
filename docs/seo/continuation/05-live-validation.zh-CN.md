# 05 线上验收：范围、步骤和恢复

2026-10-30。仍用feat/seo-foundation和现有test目标，按先隔离、后网站的顺序执行。每一步都保留实际执行结果；方案本身不是通过记录。

## 第一段：真实数据库，隔离假业务

入口为现有SEO static canary人工工作流的catalog-probe选项，沿用cloudbase-deploy-test队列；不会取消其他发布。先要求精确提交的必需CI成功，再创建seo-catalog-probe-<运行号>和seo_probe_<运行号>_前缀的九个临时私有集合。正式网站和真实商品集合均不参与。

临时函数运行与生产相同的SDK和业务保存/消费代码，只把集合名映射到上述独立前缀。映射表只允许九个逻辑名称，无法访问客户products。函数没有HTTP路由，调用还要本次临时随机凭证；凭证和签名不进入归档或日志。

依次核对：真实商品写入与待办同事务、重复检查不重复建版本、实质修改推进版本、故意让待办写入后抛错可回滚整个事务、交付期间保存被拒绝且原数据保留、撤回使页面未就绪、未知交付结果不能被新执行者接管、已知失败可以释放本次任务后重试、137个批准变体可跨页完整读取并得到完整公开摘要。最后一项使用隔离的批准资料夹具验证读取，不冒充后台批准流程验收。这里的页面摘要只是隔离数据的状态测试，不据此声称已经验证真实HTML上传。

收到完整函数结果后，删除本次明确创建的函数和集合，并读回确认；准备阶段尚未调用函数的失败只清理本次已确认创建的资源。调用结果不明则保留资源和记录，先查询函数执行结果；不在它可能仍运行时删集合，不重复执行同名测试。任何目标、权限、返回结构不符立即停止。

## 第二段：同一模板的实际候选

从当前已验收站点读取公开快照。开启记录前先做一次完整当前数据构建，覆盖未启用期间的变更；不能只凭列表字段猜正文没变。内容更新以后复用未变商品详情，只拉取变化详情，并验证公开版本与完整目录一致。商品批准编号改变而正文不变不改lastmod；历史公开日期未知就省略日期。

询盘表单初始HTML不能含构建当天的日期；浏览器接管后设置访客当地日期，并在跨午夜及恢复标签页后更新。验证同一输入跨日构建HTML一致，以及询盘输入/提交校验仍正常。新商品页面未交付时，从分类新窗口打开仍走动态详情；普通分类展开、图库、变体与询盘沿用现有交互。

## 第三段：实际网站交付与恢复

只有第二段通过、对应函数已验收并确认所有商品写入方均记录变化后，才开启记录和就绪状态读取。先登记当前实际已验收页面，不能让已有528个链接因为没登记而全部退回动态入口。

写入范围仅限候选清单中发布器拥有的差异文件、确认撤回的商品独立页和发现入口；保留历史hash资源、搜索验证文件及不归属的文件。文章服务和文章发布状态不因商品页面发布而改变。

上传沿用现有共享锁、归档、差异上传和真实HTTP检查。每批最多12件，先写正文并读回，再更新发现入口；构建和静态hash资源上传不冻结整个商品后台。写入结果未知时，原占用保留，必须确认旧执行者已结束并核对对象最终字节，不能只等30秒就解锁。

A→B→A分清两种情况：代码/样式退回A时仍使用当前商品与文章内容；业务内容不会随代码一起回退。当前新模式已加入“失败包归属核对后，用当前内容重新交付”的分支。已确定所有上传结果的失败会释放旧执行者和任务占用，让下一次重新交付；未知上传不走这个释放入口。历史静态快照的直接恢复在记录开启时拒绝，旧程序配当前内容的长期归档和恢复入口仍待实现，未验收前不开自动交付。

现网故障注入先用独立临时路径和临时函数，不对客户商品做撤回演练。最后只读抽查真实商品HTML、API最新内容、canonical、sitemap、图片、404、缓存及询盘打开。任何API内容与候选不符、未知上传、外部配置变化或其他发布占用，停止下一批并保留记录。需要关闭记录开关时，先停新任务，持同一共享部署锁核对旧执行者和未知写入均已结束；协调记录仍在占用时不能靠关闭开关放行公开保存。

## 首轮执行中发现的清理问题

真实业务8项已通过，第一张测试表的DeleteTable却返回FailedOperation.Timeout。完整目录证明它实际已删除，这不是可以靠同名盲重试判断的情况。现场已完成其余7张表的逐项清理及全量目录核对，临时函数也确认不存在。正常业务集合、6个正式SEO集合和网站文件未进入删除清单。

清理器增加删除后的完整目录读回、有限重试、失败事件保存和分页读取；若函数没有完整返回，不把HTTP调用返回本身当作执行结束。只有返回的站点、运行号、10项结果与零业务写入均相符，才允许自动清理。完整规则和实际失败记录一并保留，不删除第一次失败的运行。

参考[腾讯云DeleteTable接口与错误码](https://cloud.tencent.com/document/api/876/127967)。文档列出超时错误，但不能从这个通用提示推断网站数据库不可用或必须升级；本轮实际业务读写已成功，删除结果由实际目录确认。
