# 02 公开页面请求：先测量，重构暂缓

> 2026-11-12评审后修订。本轮设计只保留调用测量；没有证据要求迁移商品请求或新建公共请求层。分类初始HTML与分页不依赖本模块重构。

## 当前能确认什么

先前“Blog分类请求400”不是已证实的页面故障。接口读商品导航分类，合法family即使无子类也能200、空列表；54份美国报告的222次请求全部200。旧采集脚本删除了查询串，不能据此判断网页漏参。[复核](evidence/taxonomy-trace-review.json)。当时的样本还没有证实重复调用。11 月 21 日的真实目录浏览器记录找到了一组重复，见下方。

11月17日补查文章页的6份美国Before样本：每次分别请求headphones、ai-gadgets、toys、misc各一次，共24次分类请求，全部200。源码 `SiteHeader.astro` 先用Set汇总family，再用一次结果更新桌面与手机两组菜单。这批首轮加载没有同一family重复调用的证据，因此没有为此重写请求层；它仍不能代替换页、重新联网等动作的完整测量。

现有 `lib/api-url.ts`、`lib/api-envelope.ts`、`islands/shop/api.ts` 和 `catalog-taxonomy.ts` 已承担地址、响应及公开业务解码；React Query主要用于后台。不能因为库已安装，就把商品图库、变体、报价和询盘的请求整套迁移。

## 先交付的测量

在PERF-1相同代表页、设备与动作下，列出请求调用方、允许公开参数、发起时间、取消/完成时间、响应状态、传输字节、触发动作和结果是否使用。区分首轮刷新、用户翻页、预取、多个导航使用者和真正重复；有理由的多个请求不判浪费。只保存family/page等允许参数，删除凭据、搜索输入和客户数据。

一次普通分类加载记录当前列表与每个导航family各多少请求；详情记录初次读取、完整变体页及版本改变后必要重启。重点核对同条件并行读取、换商品晚响应、恢复标签页和重新联网。测量只读，不改API、不造线上商品、不提交询盘。

## 何时才设计改动

只有时序指向明确问题，才补受影响调用方的最小修改并再次评审：导航确有重复时合并对应在途请求；有可复现超时/错误缺陷时修现有封装；商品现有状态组织确实造成错误时再评估业务hook或React Query。没有问题就保留现有实现。

任何后续实现继续遵守：合法空结果是成功；400/401/403不无限重试；总时限覆盖正文；取消一位共享使用者不能打断其他人；分页不混revision、不截断必要变体；登录状态变化不得复用旧身份结果。新公共封装不是分类SSG的前置条件。

内容报价的五种公开模式按模块04处理。旧VIP字段和权限兼容仍存在，若将来动到相关请求，保留既有服务端权限判断与身份切换回归；本轮不扩展会员价功能，也不做无关价格迁移。

## 保留任务ID，明确是否执行

| MIU | 当前安排 | 验收 | 启动条件 |

## 11 月 21 日，目录菜单和筛选共用分类读取

用手机版 Chrome 详细记录了打开耳机目录、进入第二页、返回第一页的请求。三次打开目录都会读四个公开大类各一次，再额外读取一次耳机分类。页头的原生脚本先开始读取，React 目录接管后又读同一地址。两处都调用了现有地址和校验函数，响应内容属于同一个公开分类。首次打开时，前一次已经完成，第二次仍花了约 1.43 秒才返回。代表单商品页只读四个大类各一次，图库换图也没重取商品详情。本轮只修目录上已证实的同分类重复请求。

页头和目录筛选现在在同一网页内共用进行中的读取或最近五秒完成的同分类结果。保留不同分类分别读取。某处退出只结束它自己的等待，最后一处退出时才终止网络请求。失败不留可复用结果，重试和恢复缓存标签页照常请求。分类数据不进持久缓存，网站 API 的原 HTTP 缓存规则、商品报价与登录权限保持原样。

用实际产物在同一 Chrome 交替打开以前和候选的网页，分类数据来自真官网 API。三个旧版样本每次都是五次分类读取，三个候选样本每次都是四次。筛选出现时间分别为 2.906／2.373／1.864 秒与 1.880／1.862／1.863 秒，范围有重叠。六次都能访问第二页并用浏览器返回。页面与脚本由隔离浏览器从本地文件读取，绝对耗时不等于线上全页指标。候选也通过了完整网页构建，核对 589 份 HTML 和 580 个正式网址。线上部署与独立读回另行记录。

本次核对了页头脚本、目录筛选组件和共享分类读取的源码，及 Chrome 的请求记录。把“公共分类 API 有多余的调用”具体写成“耳机目录的页头和筛选分别读了同一份耳机分类”。测试确认任何一处取消都不会打断另一处，失败后可以再查，合法空分类仍返回空列表。 [请求时序与前后样本](evidence/public-category-requests-2026-11-21.json) · [Vercel 客户端请求去重参考](https://github.com/vercel-labs/agent-skills)
