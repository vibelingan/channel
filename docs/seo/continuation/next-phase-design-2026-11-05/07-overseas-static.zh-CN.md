# 07 海外静态分发：与上海后端分开验证

## 目标与现状

让海外访客就近取得公开静态资源，保留上海 API、数据库与 Blog 服务器。当前还没有部署这项 CDN，账号可见范围也未找到本站 EdgeOne 站点；不等于客户所有账号都没有。现有美国实测已经证明商品和图文慢，但不能先认定全部来自跨境。

## 首期拓扑

`独立静态子域 → 全球/海外 CDN 节点 → 现有静态托管源站`。

推荐先核对腾讯 EdgeOne 的能力、套餐与当前账号授权，再给具体域名及报价；它是候选方案，不是已经购买或保证最便宜。源站仍是现有已验收的静态产物。网站 HTML 通过受控资源前缀选择原入口或 CDN，首期不移动根域、不迁移数据库、不把后端搬海外。

| 阶段 | 可纳入 | 必须排除 / 前置条件 |
|---|---|---|
| 7A 首次试验 | 带内容 hash 的 JS/CSS、已核实许可的字体、明确公开且无撤回保护的网站素材 | API、HTML、私有预览、会员价、登录和询盘排除；商品/文章受保护图片先排除 |
| 7B 媒体（条件性） | 模块 01 生成的公开图片版本，真实公开视频 | 先证明发布引用、撤回失效、错误不缓存、版本切换和浏览器缓存边界；未证明就不接 |
| 7C 商品 HTML（以后） | 已生成的公开商品和分类 HTML | 自动发布、撤回及恢复必须一起更新 CDN；不能用一个超长 TTL 掩盖内容更新问题 |

静态子域不能解决仍走上海的首份 HTML、API 或图片响应，也不能单独完成根域 HTTP 301。三者分别测量，不能只看到脚本命中就宣布商品性能达标。

## 缓存与交付约定

带 hash 的静态包先上传、读回，再让 HTML 引用；同一地址不改字节，保留旧版本支持已经打开的页面。公开错误、鉴权响应和个性化接口不共享缓存。HTML 默认继续当前及时检查策略，Blog 继续实时公开版本；不把草稿内容加入缓存规则。

发布工具复用现有清单、摘要和共享锁，新增 CDN 时只增加对应核验和必要失效，不另造发布系统。撤回要说明源站、边缘及浏览器各自何时停止提供内容；普通 CDN 无法撤回访客已下载的副本，不能承诺“清缓存后所有设备立即消失”。

## 如何证明有效

同一时段、同一资源内容，从已验证美国出口及国内各比较原入口/CDN：冷缓存、热缓存、DNS/TLS、首字节、完整下载、缓存命中、失败和页面 LCP。至少分别保留首访与复访，避免把热缓存优势当所有用户都能得到。

验收不只看单文件下载：模块 06 的各类代表页重新测，确认 CORS、字体、图片和动态 import 正常。只对相同内容摘要比较；边缘入口变化时记录实际地点。没有改善或造成错误就回到源站，不扩大到根域。

## 费用、恢复和停止条件

开通前交付可审阅的套餐、请求/流量/证书等适用费用、余额或续费机制、账单告警与负责人；不能只说“按量计费”后无人维护。缺少套餐权限时明确指出最小授权，不推断一定有免费额度。

先准备源站可用证书、旧产物和可切换资源前缀；出现错误率上升、内容错版、私有内容可读或收益不成立就停止。恢复资源引用不需要换商品库；DNS 缓存不能即时回退，所以保留源站及旧静态文件，不在试验后立即删除。

具体云产品选择、域名、付费及正式 DNS 写入均在本设计审阅和实际报价后单独确认。本轮没有创建资源或产生新增费用。[已有配置与回退调查](../review-2026-11-04/STATIC-CDN.zh-CN.md)。
