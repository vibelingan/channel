## 怎么读和交付

先读本页决定交付顺序，再进入当前模块。每个模块把 low-level design、写入范围及一到两个 MIU 放在一起；接口由其所属模块定义，其他模块引用，不复制。MIU 是可独立实现和验证的行为，不按“加一个文件”拆任务。

继续使用原 SEO 分支，每次交付一个模块并报告具体 MIU、提交、验证和未启用能力。这里的模块不是新分支、独立服务或 Linear ticket；不自动创建 PR/任务。pricing、Blog、Hermes 和公共请求层迁移仍不在本轮运行代码范围内。

## 实际执行顺序

1. **A → B1。** 先修本地能确定的恢复缺口，再做发布状态与日志。交付后仍不开放云端恢复。
2. **C1 → D1 的人工入口 → F1 的静态 canary。** 先证明小范围静态备份/恢复闭环；canary 不涉及商品正文、数据库业务记录或函数变更。D1 对没有完整恢复包的函数写入保持关闭。
3. **C2 → D1 的前后端发布 → D2 → F1 的 API/自动恢复。** 验证函数与当前 schema/数据兼容，再启用同一次发布内的一次恢复。静态与函数的结果分开记录。
4. **B2 接入 → 商品公开范围交付与恢复。** 只在主线整合窗口接入所有公开内容写入方；没完成时不能用空清单或临时人工口头保证放开商品恢复。其余模块可先交付。
5. **E1 接入成功提交。** 默认只记录、合并和预览事件；现有稳定 sitemap 继续使用。外部通知发送器为可选能力，未配置时不伪造发送成功。上线前补对应事件验收即可，不要求先采购或接入新平台。

这是依赖顺序，不是日历工期承诺。每个模块的完成条件可单独核对；遇到缺少平台能力时，只关闭受影响的组件范围，不把整个模块虚报为完成。

## 已确定的共同约束

- 数据字段和历史记录默认保留。停用字段可以停止新增使用并标记 deprecated；不安排必经的删列/删表 MIU，也不把删除绑定到恢复窗口结束。确需删除另立有理由、有备份和影响核对的变更。本期自动流程不执行数据库 down、破坏性迁移或全库覆盖。
- 商品撤回后处理其公开 URL，与数据库删字段是不同的操作。撤回仍须移除发现入口、使 URL 返回正确状态；路径删除只限已核对的发布器所有权，不清理历史 hash 资源、平台和搜索验证文件。
- CI 失败且无线上写入不恢复；存在未知云端调用时先读回；自动恢复最多一次。通知和统计失败不改变成功发布状态。
- 产物身份 `releaseId` 与一次激活的 `activationId` 分开。恢复旧产物也产生新的激活身份，防止旧事件误认“又是同一个 SHA”。
- 测试以每个模块的正常路径和少量防止错误写入的确定性检查为主；线上沿用现有真实目标，不假设存在隔离测试环境，也不搭 Tunnel。

## 主线、pricing 与文件所有权

开始每个模块前记录当前 SEO HEAD、最新 `origin/main` 和经用户确认的 pricing ref/SHA。需要时只读 fetch；不 checkout、merge、rebase 或修改 pricing worktree。对比本模块涉及的路径和接口，若共享文件有新变更，先更新当前模块的适配决定，再实施。

模块 01 开始前已 fetch 并核对 `origin/main@37bcea5b`：本模块原有三份脚本在主线上尚不存在，package/lockfile 与本分支原基线一致。本地和远端 ref 中没有可明确识别的 pricing ref，本轮未审阅或改动其他 worktree，因此不承诺 pricing 整体无冲突。B2 的公开内容事务接入最可能重叠，明确晚于其余基础能力。现有 db 中 Alibaba 的 lease 文档及业务 guard 不归 SEO 所有，不能直接借作站点锁。

## 验证与状态回报

各模块写明计划测试名和命令；标为拟新增的测试在当前尚不存在。实现时先得到对应失败，再修行为，运行该模块的定向测试。涉及公共页面时额外遵守 `PUBLIC_PAGE_CONTRACT.md` 的 build/页面检查；涉及 SDK 时运行 SDK 合同检查。正常已有 CI 不因“只做 SEO”被跳过。

模块回报只需：`MIU / implementation / local verification / live verification / enabled scope / next dependency`。例如 C1 已实现、本地通过、线上未验证，就不能写成“静态恢复已上线可用”。最后 F1 汇总实际激活身份、普通 URL、缓存、API、数据保留及恢复耗时。

审查项落点：R1→A1；R4→A1/D1；R7→A2；R2/R6→B/D2；R3→C2；R5→C1/D1；R8→C1/C2/F1；R9→本文与每模块状态。R1/R7 已有模块 01 的本地回归证据；云端接入与现场验收仍待后续模块，其他问题不会因计划完成而关闭。
