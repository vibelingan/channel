# OEM Homepage Sync Refactor Review

Date: 2026-08-23

Corrective follow-ups: `f0ce616`, `273987d`

## Verdict

The corrected refactor is structurally sound and keeps `/oem` independent from
the homepage. Three residual contracts required repair: helper-text association,
honest no-JavaScript behavior, and the factory-video storage policy.

## Claim Provenance

`Flexible MOQ`, `agreed AQL`, `RoHS`, and the legacy partner-count claim were not
newly added by this refactor. They originated in legacy OEM content from commit
`99c0356`. Commit `c24e136` removed those claims. Their removal is not a review
finding and no restoration is requested.

## What Was Done Well

- `f0ce616` explicitly corrected the first implementation's near-total homepage
  duplication and restored an independent OEM information architecture.
- The current page keeps its own hero, capability grid, six-stage process, proof
  points, factory media, project form, and deep links.
- Only the Traditional-versus-AI comparison is shared with the homepage.
- The content model is typed and locale-backed rather than hardcoded in the page.
- Browser coverage pins structure, current claims, responsive overflow, separate
  homepage/OEM forms, factory media, and the shared custom picker.

## Resolved Findings

### R1 - Helper text was not associated with text/file controls

`ProjectForm.astro` rendered `${field.name}-hint` IDs but did not reference them
from ordinary inputs. Text and file controls now set `aria-describedby` when a
hint exists. The shared select already had this association.

### R2 - The form claimed a no-JavaScript fallback it did not have

The form uses JSON API actions and direct-to-storage upload choreography, so a
native form POST cannot preserve its security and file lifecycle. It now starts
with submission disabled, displays a `<noscript>` requirement message, and only
enables submission after the JavaScript handler is ready.

### R3 - Factory video contradicted the media policy

The 7.2 MB client-provided factory clip remains a reviewed static launch asset.
The canonical policy now names this narrow exception while retaining CloudBase
Storage as the mandatory path for new or replacement marketing videos.

## Rejected Findings

- `/headphones` is an active generated route on current main, so its back-links
  are valid and hidden-route 404 coverage is inapplicable.
- Header/footer reuse through shared site content is intentional Astro page
  composition, not duplicated navigation state.

## Validation

- Site suite, Astro typecheck, repository lint, and production build.
- Focused OEM Playwright coverage for independent structure, responsive layout,
  proof points, factory video, separate forms, and the custom picker.
- Source-policy tests for all three repaired contracts.
