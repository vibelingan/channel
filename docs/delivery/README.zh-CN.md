## 当前方案

商品继续使用SSG：首次请求收到正文，React随后读取实时API。文章由后台确认公开修订，Astro按访问请求读取公开API并返回HTML；发文章不触发GitHub内容构建，也不等五分钟任务。改网站程序仍需构建和部署。SSR本身不保证排名，真实状态码、canonical、正文、图片、链接及sitemap都要检查。

顺序为：非Agent文章闭环 → 已知可用A、无害B、恢复A → 本地内容助手 → 部署提速及海外。恢复程序不回灌数据库，不删除新字段、文章或历史资源。
