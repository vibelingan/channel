## 为什么上传曾经超时，最终怎么处理

小接口请求正常，上传2.15MB原图时，发布机普通连接曾在60秒、120秒后超时；120秒的对照只送出约1.84MB，连接读数记录到重传。这说明不能只看文件小，就认定上传一定很快；目前证据没有定位到具体线路或运营商故障。

给同一张图的上传连接单独选择BBR后，10.251秒上传成功。正式工具采用这条已验证的传输方式，仍使用标准HTTPS、证书校验和单对象短期许可。系统默认仍是cubic，其他程序的连接不跟着变。没有开启付费全球加速，没有更改防火墙、路由或存储权限。安装了本功能自己的开机模块加载文件，但没有重启整机测试，以免影响其他应用。

失败时保留原文档号、编辑链接和已完成进度。只有全部图片确认插入才报告图文完整；网络中断不触发重建文章。详细对照、限制和退出办法见实现说明。
