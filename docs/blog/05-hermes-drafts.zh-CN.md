# 05 内容助手把文章送到 Blog 草稿

2026-10-24，**本模块只交付设计，尚未实现或接通 Agent。** 本轮没有修改 HermesInfra、企业微信机器人、其运行配置或凭证。先前提前编写的接口草案已留在仓库外，不随本次交付提交。

这是一项独立于基础 Blog 的自动化功能：内容助手写好文章 → 调网站草稿接口 → 群里回复编辑链接 → 客户登录后修改、预览 → 管理员决定发布。Agent 没有发布权限。

**仓库边界：** Channel 提供业务 API，并可在本仓库提供很薄的 Agent 工具适配器。Hermes 一侧最终需要在受限的内容助手运行环境里安装/配置这个工具和凭证；本轮不改其仓库代码。配置工具也属于一次后续接入操作，不能说“网站 API 写完，群助手就自动会调用”。

一期支持文字草稿、稳定请求号去重、结果查询和登录后的编辑链接。图片由人在后台上传；Meta→Action、自动发布、定时发布、多人协作、远程图片下载和 Agent 覆盖人工文章都不包含在内。

原方案中拟用 202 和异步操作队列。本次审阅后收紧为**同步校验、单事务保存**：新建成功返回 201，同内容重复投递返回 200。没有排队就不返回“已排队”，也不为了简单草稿导入增加第二套 worker。网站公开文章的构建和发布仍是另外一条现有流程。
