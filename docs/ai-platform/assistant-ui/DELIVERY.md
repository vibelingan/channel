## 两轮自审发现和修正

本轮没有派发子 agent；以下是源码自审、真实浏览器验证和定向缺陷注入，不能称为两个独立审查员的结论。

第一轮按异步事实检查：

- 当前 conversation／turn／sequence 才能改当前回答；重复或晚到内容不再追加。停止请求中、结果未知和确认停止分别展示，final 先到时保留完成事实。
- 浏览器回归证明：回答已完成但旧读取器迟迟不结束时，第二个问题原本被内部 busy 挡住。先运行失败断言，再在终态释放本地读取器，复跑通过。
- 询盘保存使用独立的异步代次。返回聊天并继续问，不会丢掉正在保存的询盘回执；重复核对用相同 key 和内容指纹，模拟记录始终只有一条。
- 临时历史读取失败保留当前聊天并允许重试；只有明确不可恢复才清理旧可见内容。未完成的询盘核对及保存未知时暂不切换历史，避免丢资料。

第二轮按实际界面和生产构建检查：

- 单独的 Vite 入口最初与 Astro 共用缓存，出现 `jsxDEV is not a function` 白屏。浏览器挂载测试先失败；分开缓存后通过。类型检查本身没有抓到这个运行问题。
- 手机截图发现核对页第一个输入框被聊天自动跟随滚到了屏幕外。原来 `toBeVisible` 只证明 DOM 元素可见，不能证明它在当前屏幕内；新增 `toBeInViewport` 后失败。核对改成独立区域、关闭该区域的聊天跟随，复跑通过，返回聊天仍保留记录。
- 图片已逐张查看桌面产品、手机产品与手机表单。颜色、24rem 外壳和输入区沿用官网 token；产品图为明显的样例图标，尚未接实时图片。
- 实际 Astro 构建中没有预览页面或模拟内容。用构建后的文件启动临时本地服务，再在 `/`、`/headphones/`、`/oem/` 打开与关闭原 Widget，验证未配置服务时的联系入口；`/login/` 没有该入口。全部服务请求被阻断，无真实模型或后台操作。
