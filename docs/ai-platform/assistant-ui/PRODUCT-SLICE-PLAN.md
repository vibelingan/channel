# 增量：产品查询、卡片与实时比较

复用原问答、运行事务、公开产品 API 和已有卡片组件。本轮新增业务结果，不重复搭 AI 系统。原 MIU 4／5a／11：模型只输出有限的查询／澄清计划，服务器解码并执行公开只读查询；卡片和比较来自实际返回字段，不从模型文字拼产品。

普通聊天在新产品工作流启用时可生成 search／clarify／answer 计划；显式“查询当前详情”从卡片发起结构化 lookup 动作。动作和提交一起存入原消息，重试必须正文、动作均一致。只读 API origin 由服务器配置；请求不携带管理员或 VIP 凭据；模型不能提供 URL 或选择客户连接。

查询 → 当前公开目录 → 卡片；选择两项 → 纵向比较；核对最新资料 → 再查公开 API → 显示新版本，撤下的产品从当前比较中移除。无结果、查询失败、取消后晚到结果分别处理。最终结构化结果与文本在原有带版本 fence 的事务里一起提交。v1 忽略新字段，v2 严格验证。保留普通知识问答的来源门禁。

真实模型规划的配置和验收独立于确定性测试规划器；未做真实模型实测时明确报告。正式询盘提交和历史恢复不在本轮范围；未接后台的询盘确认入口继续隐藏，不能把失败的模拟保存当成可用功能。

验收：实际 React／BFF／PostgreSQL／worker 对受控公开 API 的连续浏览器操作；查询、图片、比较、刷新变更／撤下、澄清、无匹配、超时与恢复、停止后晚到结果。测试计划解码、公共投影、同 key 换动作拒绝；定向删除投影和动作校验，验证测试有效。
