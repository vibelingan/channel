# P2d4 只读预检与报告生产边界

本子单元实现完整候选和媒体元数据的只读检查，沿现有完整 source plan / manual Preview，不引入第二套 mapping、属性筛选或影像下载。输入版本和管理员身份检查前后均核对，来源变化或撤权不得返回可复用结果。所有实际采用的图片都检查，包含最后配置，不只看第一页；每件并发最多 8 个点读，超预算返回 incomplete，不能假装全部通过。临时锁为 preparing，坏类型、失效图片、坏计数或不可用旧锁为 blocked；分类独立，不因缺主分类阻止可查看候选。

返回值明确为 unsealed-inspection，只有诊断、版本和媒体摘要，没有 PreparationReport 的 schemaVersion/state/mediaReady，不能直接传给现有报告持久化契约。当前仅模块接线和测试，不注册 HTTP/worker，不启用 normal/issues/preparing 过滤。后续生产者必须取得媒体保护并完成最终版本验证，才转换成持久报告；普通 actorId 不能冒充后台服务身份。

必须覆盖：完整源候选、未分类、人工商品、坏来源/坏最后配置、105 配置末页缺图/坏媒体、两种正确 provider、数组/未知 provider、fresh/stale/corrupt lock、缺计数/异常计数、唯一图片去重/并发上界、预算耗尽、检查中来源/商品/身份变化、无预留身份/无暂存或业务写入、受控诊断不包含 rejected values。真实文件可读性由后续存储/公开读回验收验证，本模块只检查元数据。

媒体绑定变更和删除与报告提交的并发窗口尚须专门的保护协议。本轮不会用两次只读相等冒充事务证明，也不会持久化这个未封存结果或把它用于发布授权。P3 真正大媒体事务协议、后台服务授权和 P5 影子回填仍是启用门槛。


实际边界补充：有效的共享图片计数值、临时锁 owner/time 不属于内容摘要，避免别的商品正常发布使当前准备结果无故失效；有效性和锁仍逐张检查。已知复制失败、不可导入的配置图片返回 blocked/edit，人工配置图覆盖可恢复；未知待复制图片返回 preparing/retry-media。旧批准记录损坏或商品 ID 不匹配不能算 Preview 可用。完整来源计划复用真实 Preview 的分页字节检查，不二次读取或建立另一套投影。

最终本地证据：33 项检查模块测试、10 项真实 Playwright loopback 传输测试；广泛消费者 2485/0/0；17 个检查缺陷、3 个传输缺陷各有正常控制且被检出。构建浏览器 151 项验证的是已接线的共享 Preview 和既有业务流程，检查模块尚未注册，不将浏览器通过当成报告生产验收。真实三件时钟的已存只读副本检查通过，仍非云端 resync/文件像素/真实发布证据。

相邻测试基础设施只给 get/list 和精确 list 路由转发加一次 ECONNRESET 重试，持续重置恰好两次后失败，400/503 不重试，任何写请求不自动重发。原分类核对故障注入仍被真实浏览器检出。首次连接重置的底层原因未独立复现；本项不声称修复应用侧请求恢复或服务端网络。
