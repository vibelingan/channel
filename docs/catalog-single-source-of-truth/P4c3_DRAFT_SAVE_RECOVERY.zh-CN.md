# P4c3：草稿保存确认与恢复

新增 `catalog-draft-save.ts`，使用已有 `save-draft` Root、绑定保存和原子停止协议。输入在第一个 await 前复制，原 nonce 与版本只生成一次；请求未到达时，同页显式继续只发送原输入。刷新后不从恢复指针重建正文，可以检查原保存或停止原任务。已绑定的 Root 后来缺失时保持未决，不能创建替代停止记录。

保存成功需要原 Root 的 saved 回执及当前私有商品版本一致。另一标签页后来改过商品时返回 historical，保留当前商品；保存响应丢失后只查询原任务，不再次写商品。停止不会撤销已保存的文字。恢复记录按 actor、endpoint、draft 命名空间隔离，只含标识及服务器 digest，不含正文或 JWT。存储无法持久化时不发第一次写请求；删除恢复记录失败仍可再次关闭。

此单元尚未接 RecordForm，不改变已有编辑入口。新照片仍受服务端准备门槛保护；没有放宽媒体检查、修改分类、发布商品或部署。照片保存、live 编辑、会话失效时保留表单及最终 test 真实数据验收仍待完成，`fullDeliveryReady=false`。
