来源单张导入现在记录目标字段并预留一个位置。对应ImageManager在文件接纳和可用位置显示上都计入该预留，显示Adding Alibaba photo；只有一个空位时暂不接纳第二张，两空位时仍可并行上传一张。正在上传的同一字段不能再启动来源添加。推导的容量约束是“已选 + 待上传 + 待复制 ≤ 上限”；完成只把待处理位置换成已选位置，失败释放预留。删除、排序、文字编辑仍可用。Keep/Use在媒体、保存、只读或丢弃处理中禁用，回调也有忙状态保护；结束后恢复，用户显式Keep仍能正常保存。
