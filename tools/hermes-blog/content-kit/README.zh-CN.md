# 给内容助手的 Blog 技能包

本包只安装一份有条件使用的网站写作技能，不包含网站凭证、发布机 MCP、固定文章号或旧的十四天试跑配置。可以交给内容助手自行检查并安装。

## 允许做什么

在当前内容助手使用的 Hermes 目录中安装 channel-blog-writing。它负责：客户要求网站文章时整理正文、搜索摘要和配图；先存 VibeKB；只有明确要求网站草稿时再交接。

不改现有 config.yaml、SOUL、MCP、模型、客户绑定、其他技能或服务。安装不需要重启。不要安装到发布机，也不要索取网站密钥。

## 安装

先解压到自己的工作目录，阅读技能和本页，再运行：

```sh
python3 install.py --home "$HOME/.hermes"
```

如实际使用其他 Hermes home，先核对真实运行进程，再传入那个目录。不要新建另一套助手。

安装器校验技能摘要，只覆盖它自己先前安装且未被人修改的版本；遇到未知同名文件会停止。更新前备份旧技能。重复安装同一版不修改其他文件。

安装后用原生 skills_list 和 skill_view 确认可读取 channel-blog-writing。报告安装结果和摘要，不执行写文章、入库或发布测试。

## 等自查结果后再接交接

这份技能不会凭空创建任务队列。请继续核对 VibeKB 的正确客户工作区、真实文档 ID，以及已有协作入口和 pipeline 的用途。

内容机当前配置的 pipeline 使用 host.docker.internal；只读检查发现该原生运行环境无法解析它，工具发现为空。不要因此改整个 MCP 或擅自启动新队列，先报告实际自查结果。

正式交接未接通时，只能报告文章已入库及真实文档 ID，不能说网站草稿已保存。网站保存、凭证维护与去重由发布机承担；人最后去网站后台审核上线。
